# NUR 223 Exam 4 Day 1 — 12-Game Study Arcade

Single-page offline-capable HTML study arcade. Includes the original eight games and four new games: Code Blue Simulator, Ventilator Troubleshooting Lab, ABG Detective, and Medication Decision Lab. Progress is saved locally in each browser.

## Publish

Create a GitHub repository; upload `index.html`, `README.md`, and `.nojekyll` to the repository root. In **Settings → Pages**, choose **Deploy from a branch**, **main**, and **/(root)**.

The clinical scenarios are educational practice and not substitutes for local clinical protocols.
