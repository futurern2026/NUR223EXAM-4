# NUR 223 Exam 4 — Complete GitHub Pages Study Arcade

This is the combined final homepage and the latest supplied versions of the Days 1–3 study content.

## Files
- `index.html` — homepage with all three days, medication games, and EKG Mastery
- `day1.html` — Day 1 study arcade
- `day2.html` — Day 2 study arcade
- `day3.html` — Day 3 16-game arcade (includes Day 3 Medication Mastery)
- `day1-medication-mastery.html` — Day 1 Medication Mastery
- `day2-medication-mastery.html` — Day 2 Medication Mastery
- `ekg-mastery.html` — EKG Mastery

## Publish to an existing GitHub Pages repository
1. Extract the ZIP.
2. Upload **all the files** into the same folder as your current website `index.html` (usually the repository root).
3. Replace matching files and commit the changes.
4. Keep your existing GitHub Pages branch/root settings.

## Notes
- Day 3 Medication Mastery is part of `day3.html`, not a separate file.
- Progress is saved in browser localStorage. Keeping the same website address and browser generally retains existing progress.
- The page uses relative links, so it works from a GitHub Pages project repository.
